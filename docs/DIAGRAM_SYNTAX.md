# 代码图表语法与模板

代码图表使用文本描述结构和数据，由本项目的解析器生成可预览、导出及转为画布副本的图形。当前支持 22 类图表的明确语法子集；本页帮助选择模板、阅读源码和组合已支持的表达方式。逐类语法与未支持项以 [格式说明](FORMATS.md#代码图表语法子集) 为准。

## 从模板开始

1. 打开“代码图表”，在模板库中按类型、分类或关键词查找示例。搜索同时匹配名称、说明和源码，因此也可输入语法关键字或注释中的词语；卡片显示示例行数，列表显示实际示例数量。
2. 选择模板，将源码放入左侧编辑区。已有内容被替换前会提示确认，替换可撤销。
3. 阅读源码中的 `%%` 注释，先改名称和数据，再调整节点、关系、分组或样式。
4. 在左侧移动光标或选中文本，右侧高亮对应图元；“定位图形”可将目标移到预览中央。
5. 保存为 `.owflow` 保留源码与全局风格；导出图表源码只保存文本。需要手动移动图形时，创建独立画布副本。

模板都使用普通源码，可以继续编辑和保存。模板内的示例名称、任务、日期和数值只用于展示表达方式，不连接真实服务，也不自动更新。

## 阅读源码与注释

第一条有效语句声明图表类型，例如 `flowchart LR`、`sequenceDiagram` 或 `gantt`。不同类型使用不同的数据与关系语法；不要把一种类型的指令直接放入另一种类型。

以 `%%` 开头的独立注释行用于说明分段、字段含义和绘制目的，不生成图元，也不出现在图像导出中。注释可以留在源码里，随原生文件和文本导出保存。模板中的注释是使用提示，删掉它们不会改变图表数据。

```text
%% 说明本图的用途
flowchart LR
  %% 节点 ID 用来建立关系，方括号里是显示文字
  request[收到申请] --> review{资料完整？}
  review -->|是| done[完成处理]
  review -->|否| request
```

光标定位依据源码范围与图元 ID，不靠文字名称猜测，因此同名节点仍能分别定位。同一条语句可能生成卡片、文字、线条等多个图元；空白、注释和纯布局设置没有对应图元时不高亮。语法错误会保留行号，新输入尚未生成预览时会暂停旧高亮。

## 复杂模板导览

## 内置扩展写法

部分便捷指令是本项目提供的扩展，保存为源码后，其他读取器未必接受。原生文档由本项目读取；需要跨工具交换静态外观时可导出 SVG/PNG。

| 类型 | 扩展与用途 |
| --- | --- |
| 饼图 | `innerRadius 0.6` 设置内环，`showLegend false` 隐藏图例 |
| 柱线图 | `bar "实际" [10,20,30]` 和 `line "目标" [15,25,35]` 命名系列；`y-ticks 5` 设置纵轴分段，`showLegend false` 隐藏图例 |
| 桑基图 | `title`、`showValues`、`linkColor` 和 `nodeAlign` 控制标题、数值、流带颜色与层级对齐 |
| 雷达图 | `rotation` 改变轴起始角度；`curveStyle ID` 设置指定曲线的有限样式属性 |
| 矩形树图 | `title` 设置独立标题，`showValues` 控制区块与明细中的数值显示 |
| 用户旅程 | `actorColor 名称:颜色` 统一参与者姓名、泳道和任务标记配色 |
| 看板 | 列 `@{limit:2}` 显示在制品数量与超限提醒；卡片的 `due`、`tags`、`progress` 展示日期、标签和进度条 |
| 数据包图 | `bitsPerRow` 调整每行位数，`showBits` 控制逐位编号，`bitOrder` 同时改变位号和字段方向，`startBit` 只改变行偏移标签 |

样式指令的支持属性随图表类型变化。数据图表样式颜色只接受 `#RGB` 或 `#RRGGBB`，未知属性或外部地址会报错。先使用对应模板中的样式写法，再对照 [逐类支持表](FORMATS.md#代码图表语法子集) 调整。

## 修改前注意

- 保留被其他语句引用的 ID，或同时更新引用。显示文字与 ID 的用途不同。
- 数据图表按数值生成几何，改动数值会重新计算比例和位置。日期、范围、依赖与引用也会校验。
- 源码样式只接受各类型明确支持的属性，不执行脚本、外部资源或任意页面样式。
- 全局绘图风格属于原生文档设置。“经典”保留编译后的源码外观，其他风格会统一调整颜色与线条；纯文本导出不携带风格，可编辑画布副本保留创建时的具体外观。
- 画布副本与源码不双向同步；调整数据或关系后，需要从源码重新生成副本。

图形容量、文件大小和导出限制见 [格式说明](FORMATS.md#当前容量限制)。复杂布局可能需要在画布副本中继续整理，模板覆盖的是已实现能力，并不表示支持所有外部语法。
