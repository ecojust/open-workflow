# 文档与格式兼容

本文对应开发中的 Open Workflow 0.1.0。所有导入内容最终进入同一套自研场景模型；文件扩展名不代表完整兼容相应产品。

## 格式一览

| 格式 | 导入 | 导出 | 说明 |
| --- | --- | --- | --- |
| `.owflow` | 是 | 保存 / 另存为 | Open Workflow v1 JSON，保留应用可编辑数据 |
| `.drawio`、draw.io `.xml` | 是 | 是 | 原始或压缩 XML、多页面；导出单页基础图形 |
| `.excalidraw`、相同结构的 `.json` | 是 | 是 | 基础形状、文字、连线、笔迹、内嵌图片 |
| `.mmd`、`.mermaid` | 是 | Mermaid 文档可导出 | 源码保留，预览使用自研子集解析器 |
| `.svg` | 否 | 整图或选区 | 静态矢量图，不含文档编辑状态 |
| `.png` | 可作为画布图片插入 | 整图或选区 | 导出场景图片；图片不是可编辑节点结构 |
| 无边记 / Microsoft Whiteboard 专有格式 | 否 | 否 | 仅参考产品体验 |

非原生文件导入后，在 `importSource` 保存来源文件名、格式和原始文本。导入说明列出已识别的简化、替换或跳过项；无法解析的文件会报错，其他已打开文档保留。保存创建 `.owflow`，不复写来源文件。“导出 → 导入时的原文件”返回导入时的原文，之后在画布上的修改不会写入这份原文。

## 原生 `.owflow`

文件使用 UTF-8 JSON，顶层字段如下。完整 TypeScript 定义见 [`src/core/types.ts`](../src/core/types.ts)，读写校验见 [`src/core/documents.ts`](../src/core/documents.ts)。

| 字段 | 含义 |
| --- | --- |
| `format` / `version` | 固定为 `"open-workflow"` / `1` |
| `id` / `title` / `kind` | 文档标识、标题、`flow` / `board` / `mermaid` |
| `scene` | `elements`、背景色 `background`、网格 `grid`、可选默认样式 `defaultStyle` |
| `source` | Mermaid 源码；流程图、白板一般为空字符串 |
| `createdAt` / `updatedAt` | ISO 时间 |
| `importSource` | 可选的原始导入文本与来源描述 |

`elements` 包含三类对象：

- `shape`：矩形、椭圆、菱形、便签、文字或图片，保存位置、尺寸、文本、样式及锁定状态。
- `edge`：两个端点、可选绑定节点 ID、文字标签、箭头和直线/正交路由。绑定后的绘制端点由几何层计算。
- `stroke`：世界坐标中的笔迹点列、样式及锁定状态。

元素 `style` 在原有颜色、填充、线宽、字号、对齐、透明度和 `dashed` 字段上，增加两个可选字段：

| 字段 | 值 | 旧文档兼容行为 |
| --- | --- | --- |
| `roughness` | `clean`（整洁）或 `sketch`（手绘） | 缺失时为 `clean` |
| `strokePattern` | `solid`、`dashed` 或 `dotted` | 缺失时由旧 `dashed` 布尔值还原实线或虚线 |
| `scene.defaultStyle` | 一份完整元素样式 | 缺失时使用应用默认样式 |

格式版本仍为 `1`，当前读取器可以直接打开缺少这些字段的旧文档。写入时规范化样式，并保持 `dashed` 与 `strokePattern` 一致；有 `strokePattern` 时以它为准。旧版软件不一定能保留新增样式字段，跨版本往返应保留原文件。

全局整洁/手绘、线型、线宽或颜色修改会将本次属性写入所有现有元素（**包括锁定元素**）和 `defaultStyle`，后者用于之后创建的元素。单个图形仍有独立的 `style`；再次全局修改同一属性时会覆盖该属性的独立设置。

Mermaid 文档以 `source` 为准，预览和图像导出时重新编译。“转为可编辑流程图”创建新文档，不反向改写原始 Mermaid。选区、光标、平移缩放视口、撤销历史和桌面磁盘路径不写入 `.owflow`。

当前拒绝未知原生格式版本、重复元素 ID、无效坐标、悬空节点绑定等结构错误。保存前使用同一套校验器检查数据；不会把不可重新打开的数据报告为成功保存。

## 整图与选区图像

画布右键菜单可以导出整图或选区 SVG/PNG，选区导出只包含实际选中的元素。所选连线如果连接选区外的节点，会先计算完整场景中的可见端点，再以自由端点导出；未选中的节点不会被自动加入。导出不修改原文档的绑定。

整洁/手绘、实线/虚线/点线等外观使用与画布相同的 SVG 渲染代码。画布点阵、选框、端点手柄和工具栏属于编辑辅助，不进入图像。SVG/PNG 不包含撤销历史或可重新打开的原生文档数据。

## draw.io

支持 `mxGraphModel` 和 `mxfile`。后者可包含多个 `diagram`：直接 XML、XML 文本，以及 Base64 + raw DEFLATE + URI 编码页面均可导入。每个页面创建独立的文档标签。

基础转换包括矩形、椭圆、菱形、便签、文字、内嵌 PNG/JPEG/WebP、文字标签、节点引用、自由端点、箭头、直线/正交连线及部分样式。导出为普通 `mxCell`；笔迹和部分内部属性使用 `openWorkflow*` 元数据辅助本软件重新导入。

整洁/手绘映射到 `sketch`，实线/虚线/点线映射到 `dashed` 和 `dashPattern`；自定义虚线间隔会近似为当前支持的线型并提示。手绘标记得到保留，具体抖动外观可能不同。画布默认样式存于 `mxGraphModel` 的 `openWorkflowDefaultStyle` 属性，供本软件重新导入；其他软件不一定保留该扩展元数据。

会提示的简化包括：分组展开为普通元素；相对定位转换为画布坐标；未知形状替换为矩形；旋转、渐变、圆角、阴影、特殊字体简化；手工折点与特殊路由简化；HTML 富文本转换为纯文本。外部图片或 SVG 图片显示占位矩形，不联网加载。复杂图需要对照原图复核。

包含 `DOCTYPE` / 实体声明的 XML 会被拒绝。页面的压缩数据损坏、父子关系循环或 ID 冲突也会报错。

## Excalidraw

读取 `type: "excalidraw"` 的 JSON。支持矩形、椭圆、菱形、独立文字、绑定到图形或边的文字、箭头、直线、自由笔迹和文件中内嵌的 PNG/JPEG/WebP 图片。已删除的元素不导入，连线绑定根据元素 ID 恢复。

`roughness` 为正数时映射为本软件的手绘外观，`strokeStyle` 映射为实线/虚线/点线。手绘标记保留，但抖动强度和具体笔迹采用自研近似；纹理填充、压感、旋转、分组、框架/裁剪、翻转、特殊箭头和字体外观会被简化或忽略，并对已识别的限制给出提示。未知元素类型会跳过；缺失或不支持的图片使用占位矩形。连线所引用的节点不可用时，保留自由端点并提示。

导出为 Excalidraw v2 JSON；便签作为矩形附带 `customData.openWorkflow`，文字作为独立或绑定文字元素，默认样式存于顶层 `openWorkflow.defaultStyle`。线型写入 `strokeStyle`，整洁/手绘写为 `roughness: 0 / 1`；重新导入可恢复本软件的样式含义，其他软件可能删除扩展元数据。它是基础格式转换，不提供 Excalidraw 的协作、插件或完全相同的手绘渲染效果。

## Mermaid 子集

本项目自己解析文本、布局和生成 SVG，不加载 Mermaid 包。语法错误显示行号，部分错误还包含列号；未知语法会报错。源码中的 HTML 不执行，图形标签使用纯文本。

流程图支持：

- `flowchart` 或 `graph`，方向为 `TD`、`TB`、`LR`、`RL`、`BT`。
- 节点 `A[矩形]`、`A(圆角文字)`、`A((圆形))`、`A{菱形}`，以及独立节点或连接链。
- `A([体育场形])`、`A[[子流程]]`、`A{{六边形}}` 可解析，分别简化为椭圆、矩形和菱形；当前圆角矩形也按普通矩形绘制。
- 实线、虚线、粗线、无箭头及双向连接，例如 `-->`、`---`、`-.->`、`==>`、`<-->`；标签可以写为 `-->|标签|` 或 `-- 标签 -->`。
- 双引号标签、`%%` 注释、分号分隔；标签换行使用 `<br/>` 或 `\n`。

```text
flowchart TD
  start([开始]) --> review{是否通过？}
  review -->|通过| done[发布]
  review -->|修改| edit[完善方案]
  edit --> review
```

时序图支持 `sequenceDiagram`、`participant`、`actor`、`as` 别名、消息箭头、`Note left of` / `right of` / `over` 和 `autonumber`。消息可隐式声明参与者，箭头外观会统一为本软件的基本样式。

```text
sequenceDiagram
  participant User as 用户
  participant App as 应用
  autonumber
  User->>App: 打开文档
  App-->>User: 显示画布
  Note over User,App: 数据保存在本地
```

暂不支持其他 Mermaid 图表类型、`subgraph`、样式/主题/初始化/交互指令，以及时序图的激活区、循环、条件分组等。文本可以保存为 `.owflow` 或导出 `.mmd`；只有能够成功编译的源码才可导出图像或转换为可编辑流程图。不支持将任意手工流程图反向生成 Mermaid 源码。

## 当前容量限制

| 项目 | 限制 |
| --- | --- |
| 原生文档及单个输入文件 | 50 MiB（按 UTF-8 字节计算） |
| 画布 | 最多 5,000 个元素，笔迹合计最多 100,000 个点 |
| 插入的单张图片 | PNG/JPEG/WebP，最多 10 MiB；在文档中内嵌 |
| draw.io / Excalidraw 转换输入 | 另有 `20 × 1024 × 1024` 字符长度限制 |
| draw.io 压缩页 | 解压后的字节量最多 20 MiB；一次最多 100 页 |
| Mermaid 源码保存 | 最多 500,000 字符 |
| Mermaid 实际编译 | 最多 200,000 字符；流程图 400 节点 / 800 连线；时序图 40 参与者 / 800 事件 |
| PNG 导出 | 最大边长 8,192 像素，约 2,000 万像素预算；大场景会降低输出比例 |

转换后的文档同时包含场景和保留原文，可能比输入文件大；超过原生文档限制时会拒绝导入。以上是保护性上限，不代表接近上限的复杂图已经达到流畅编辑性能。
