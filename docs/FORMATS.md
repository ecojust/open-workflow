# 文档与格式兼容

所有导入内容最终进入同一套自研场景模型；兼容范围以本文列出的结构与语法为准。

## 格式一览

| 格式 | 导入 | 导出 | 说明 |
| --- | --- | --- | --- |
| `.owflow` | 是 | 保存 / 另存为 | Open Workflow v1 JSON，保留应用可编辑数据 |
| 图形 XML：`.drawio`、对应结构的 `.xml` | 是 | 是 | 原始或压缩 XML、多页面；导出单页基础图形 |
| 白板 JSON：`.excalidraw`、对应结构的 `.json` | 是 | 是 | 基础形状、文字、连线、笔迹、内嵌图片 |
| 文本图表：`.mmd`、`.mermaid` | 是 | 代码图表文档可导出 | 源码保留，预览使用自研子集解析器 |
| `.svg` | 否 | 整图或选区 | 静态矢量图，不含文档编辑状态 |
| `.png` | 可作为画布图片插入 | 整图或选区 | 导出场景图片；图片不是可编辑节点结构 |

扩展名 `.drawio`、`.excalidraw`、`.mermaid`，以及持久化中的 `drawio`、`excalidraw`、`mermaid` 值，是为读写既有文件保留的兼容标识，不用于本项目的界面或组件命名。文件内容还必须符合对应结构，不能仅靠扩展名判断兼容性。

非原生文件导入后，在 `importSource` 保存来源文件名、格式和原始文本。导入说明列出已识别的简化、替换或跳过项；无法解析的文件会报错，其他已打开文档保留。保存创建 `.owflow`，不复写来源文件。“导出 → 导入时的原文件”返回导入时的原文，之后在画布上的修改不会写入这份原文。

## 原生 `.owflow`

文件使用 UTF-8 JSON，顶层字段如下。完整 TypeScript 定义见 [`src/core/types.ts`](../src/core/types.ts)，读写校验见 [`src/core/documents.ts`](../src/core/documents.ts)。

| 字段 | 含义 |
| --- | --- |
| `format` / `version` | 固定为 `"open-workflow"` / `1` |
| `id` / `title` / `kind` | 文档标识、标题；`flow` / `board` 是旧流程图/白板文档保留的兼容值，现统一在画布中编辑；`mermaid` 是代码图表文档保留的兼容值 |
| `scene` | `elements`、背景色 `background`、网格 `grid`、可选默认样式 `defaultStyle` |
| `source` | 代码图表源码；画布文档一般为空字符串 |
| `diagramStyle` | 可选的代码图表全局风格 ID；缺失或未知值按 `classic` 读取 |
| `createdAt` / `updatedAt` | ISO 时间 |
| `importSource` | 可选的原始导入文本与来源描述 |

`elements` 包含三类对象：

- `shape`：矩形、椭圆、菱形、三角形、六边形、星形、平行四边形、圆柱、云形、四方向大括弧、分区框架、便签、文字或图片，保存位置、尺寸、文本、样式及锁定状态。
- `edge`：两个端点、可选绑定节点 ID、文字标签、箭头和直线/正交路由。绑定后的绘制端点由几何层计算。
- `stroke`：世界坐标中的点列、样式及锁定状态；可选 `brush` 保存笔触类型，`pressures` 保存逐点压力；可选 `closed: true` 将点列闭合并按 `style.fill` 填充，用于扇区、流带等图形。

三类元素都可携带 `groupId`，表示单层组合；缺失表示没有组合。框架是 `shape: "frame"` 的可编辑边框与标题，拖动时根据几何范围查找内容，不保存父子关系或裁剪区域。

笔迹的新增可选字段如下，格式版本仍为 `1`。两个字段都缺失时继续使用旧笔迹绘制方式，不改变旧文档的内容比较结果。

| 字段 | 值与校验 | 用途 |
| --- | --- | --- |
| `brush` | `pen`、`pencil`、`marker`、`brush`、`highlighter`、`rainbow` | 圆头笔、铅笔、马克笔、毛笔、荧光笔、彩虹笔 |
| `pressures` | 与 `points` 等长的数值数组，每项介于 `0..1` | 保存逐点压力；缺失时使用稳定的默认压力 |

粗细、颜色和不透明度继续保存于 `style`，六种笔触均根据逐点压力改变可见粗细。荧光笔额外使用 `0.32` 的透色系数，因此把不透明度调至 100% 后仍呈半透明；彩虹笔由路径行程决定多色变化，在色段边界插值压力。平滑设置只影响绘制时记录的点列，不新增文件字段；笔触面板偏好和临时激光指示不写入文档。已创建笔迹的类型与压力参与保存、草稿、复制和撤销重做。旧版读取器可能忽略这些新字段，跨版本编辑应保留原文件。

四方向大括弧使用 `brace-left`、`brace-right`、`brace-top`、`brace-bottom` 形状值，保留尺寸、内侧文字、样式与节点绑定。括弧是开放曲线，不填充封闭区域；原生文件和 SVG 导出完整保留其形状。新增形状不改变格式版本，但旧版读取器可能无法识别它们。

元素 `style` 在原有颜色、填充、线宽、字号、对齐、透明度和 `dashed` 字段上，增加两个可选字段：

| 字段 | 值 | 旧文档兼容行为 |
| --- | --- | --- |
| `roughness` | `clean`（整洁）或 `sketch`（手绘） | 缺失时为 `clean` |
| `strokePattern` | `solid`、`dashed` 或 `dotted` | 缺失时由旧 `dashed` 布尔值还原实线或虚线 |
| `scene.defaultStyle` | 一份完整元素样式 | 缺失时使用应用默认样式 |

格式版本仍为 `1`，当前读取器可以直接打开缺少这些字段的旧文档。写入时规范化样式，并保持 `dashed` 与 `strokePattern` 一致；有 `strokePattern` 时以它为准。旧版软件可能无法识别新增形状，也不一定保留组合、闭合区域或新增样式字段，跨版本往返应保留原文件。

全局整洁/手绘、线型、线宽或颜色修改会将本次属性写入所有现有元素（**包括锁定元素**）和 `defaultStyle`，后者用于之后创建的图形和连线。新笔迹的颜色、粗细和不透明度使用笔触面板的独立设置。单个图形仍有独立的 `style`；再次全局修改同一属性时会覆盖该属性的独立设置。

指定 `brush` 的笔迹按专用笔触渲染，不叠加 `roughness` 或 `strokePattern`；颜色、粗细与不透明度继续参与绘制，但彩虹笔使用自己的颜色序列。没有笔触和压力元数据的旧笔迹保持原风格行为。

代码图表文档以 `source` 为准，预览和图像导出时重新编译。创建可编辑副本会生成独立画布文档，不反向改写原始源码。选区、光标、平移缩放视口、撤销历史和桌面磁盘路径不写入 `.owflow`。

统一画布入口不迁移或重写旧 `flow` / `board` 类型，已保存文档仍可直接打开。流程图和白板模板只是插入原生场景元素，不改变当前文档类型。连续绘制工具锁、新建连线路径和箭头默认值是当前编辑器偏好，不写入文件；实际创建的边仍保存自己的 `route`（`straight` / `orthogonal`）和 `arrow`（`none` / `end` / `both`）。

自动保存开关是当前设备的偏好，也不写入原生文件。它只控制本地草稿；手动保存文件始终同步草稿。草稿与文件保存的区别见 [README](../README.md#保存到哪里)。

局域网共享传输同一套经过校验的文档数据，保留画布内容、代码图表源码与风格。共享时不发送 `importSource` 中的导入原文，也不提供桌面磁盘路径或文件访问权限；网页下载的 `.owflow` 因而不含这份导入原文。服务地址、授权令牌、会话 ID、共享版本号和连接状态属于运行时信息，不写入原生文档。自动保存开关只影响本地草稿，不暂停共享同步；网络修改也不会自动写入桌面原文件。操作和冲突处理见 [局域网共享](SHARING.md)。

`diagramStyle` 支持十种风格：`classic`（经典）、`minimal`（极简）、`blueprint`（蓝图）、`ink`（水墨）、`sketch`（手绘）、`forest`（森林）、`ocean`（海洋）、`sunset`（落日）、`lavender`（紫雾）、`midnight`（夜色）。此字段随原生文件和本地草稿保存，参与内容比较及撤销重做，格式版本仍为 `1`；旧文档默认使用经典风格，旧版读取器可能忽略新字段。

当前拒绝未知原生格式版本、重复元素 ID、无效坐标、悬空节点绑定等结构错误。保存前使用同一套校验器检查数据；不会把不可重新打开的数据报告为成功保存。

## 整图与选区图像

画布右键菜单可以导出整图或选区 SVG/PNG，选区导出只包含实际选中的元素。所选连线如果连接选区外的节点，会先计算完整场景中的可见端点，再以自由端点导出；未选中的节点不会被自动加入。导出不修改原文档的绑定。

代码图表工具栏的“导出图片”提供“PNG 图片”和“SVG 矢量图”，不需要先生成画布副本。导出使用当前源码与全局图表风格；解析中、源码有误或预览尚未对应最新源码时，入口不可用。图像包含完整图表，不包含左侧代码、语法说明或光标高亮；需要保留可编辑源码与风格时，另存 `.owflow`。

整洁/手绘、实线/虚线/点线及六种笔触使用与画布相同的 SVG 渲染代码。画布点阵、选框、端点手柄、工具栏、激光指示与代码光标高亮属于编辑辅助，不进入图像。SVG/PNG 不包含撤销历史或可重新打开的原生文档数据。

## 图形 XML

支持 `mxGraphModel` 和 `mxfile` 兼容结构。后者可包含多个 `diagram`：直接 XML、XML 文本，以及 Base64 + raw DEFLATE + URI 编码页面均可导入。每个页面创建独立的文档标签。

基础转换包括矩形、椭圆、菱形、便签、三角形、六边形、星形、平行四边形、圆柱、云形、框架、文字、内嵌 PNG/JPEG/WebP、文字标签、节点引用、自由端点、箭头、直线/正交连线及部分样式。导出为普通 `mxCell`；笔迹和部分内部属性使用 `openWorkflow*` 元数据辅助本软件重新导入。

整洁/手绘映射到 `sketch`，实线/虚线/点线映射到 `dashed` 和 `dashPattern`；自定义虚线间隔会近似为当前支持的线型并提示。手绘标记得到保留，具体抖动外观可能不同。画布默认样式存于 `mxGraphModel` 的 `openWorkflowDefaultStyle` 属性，供本软件重新导入；其他软件不一定保留该扩展元数据。

本项目的单层组合使用 `openWorkflowGroup` 保存，闭合点列使用 `openWorkflowClosed` 保存，供本项目往返恢复；导出没有创建完整的外部分组层级。其他软件忽略这些属性时，组合关系、闭合填充或扩展图形外观可能不同，图像交换建议使用 SVG/PNG，继续编辑建议使用 `.owflow`。

大括弧导出为带文字的开放线条，使用 `openWorkflowShape` 及坐标、尺寸元数据保存原生形状。重新导入时恢复括弧并提示兼容限制；其他软件可能只保留普通线条，无法保留括弧编辑和绑定语义。导出不会用封闭多边形代替括弧。

笔触导出为普通线条，同时用 `openWorkflowBrush` 与 `openWorkflowPressures` 保存类型和逐点压力，供本软件重新导入恢复。外部编辑器可能忽略元数据，纹理、扁头、透色、彩虹或压力变化不保证保留。导入会显示相应提示；保留完整可编辑笔触请使用 `.owflow`，交换静态外观请使用 SVG/PNG。

会提示的简化包括：外部原生分组展开为普通元素；相对定位转换为画布坐标；未知形状替换为矩形；旋转、渐变、圆角、阴影、特殊字体简化；手工折点与特殊路由简化；HTML 富文本转换为纯文本。外部图片或 SVG 图片显示占位矩形，不联网加载。复杂图需要对照原图复核。

包含 `DOCTYPE` / 实体声明的 XML 会被拒绝。页面的压缩数据损坏、父子关系循环或 ID 冲突也会报错。

## 白板 JSON

读取包含兼容标记 `type: "excalidraw"` 的 JSON。支持矩形、椭圆、菱形、独立文字、绑定到图形或边的文字、箭头、直线、自由笔迹、框架和文件中内嵌的 PNG/JPEG/WebP 图片。已删除的元素不导入，连线绑定根据元素 ID 恢复。

`roughness` 为正数时映射为本软件的手绘外观，`strokeStyle` 映射为实线/虚线/点线。手绘标记保留，但抖动强度和具体笔迹采用自研近似。`groupIds` 映射为单层组合，嵌套组合合并到最外层并提示；`frame` 转为可编辑分区框架，框架裁剪关系展开。自由笔迹可以读取原文件中与点列对应的 `pressures`，按本项目的压力规则绘制。纹理填充、旋转、翻转、特殊箭头和字体外观会被简化或忽略，并对已识别的限制给出提示。未知元素类型会跳过；缺失或不支持的图片使用占位矩形。连线所引用的节点不可用时，保留自由端点并提示。

导出 JSON 保留上述 `type` 标记和 `version: 2`；便签和三角形等扩展形状作为矩形附带 `customData.openWorkflow.shape`，供本软件恢复原形状；文字作为独立或绑定文字元素，框架导出为 `frame`，单层组合写入 `groupIds`。闭合点列导出为首尾相接的 `line`，并附带闭合元数据；默认样式存于顶层 `openWorkflow.defaultStyle`。线型写入 `strokeStyle`，整洁/手绘写为 `roughness: 0 / 1`。其他软件可能删除元数据，扩展形状及闭合填充外观不保证一致。

大括弧单独导出为开放笔迹及独立文字，`customData.openWorkflow` 保存括弧形状、尺寸、文字与布局信息。重新导入时恢复为原生括弧并显示兼容提示；其他软件可能无法保留这些元数据或括弧的绑定语义。

专用笔触以自由笔迹输出，在 `customData.openWorkflow` 保存 `brush` 和 `pressures`，并写入兼容的顶层压力数组。本软件重新导入会恢复类型、逐点压力与样式，并提示外观兼容边界；其他编辑器可能显示为普通笔迹，或移除自有元数据。铅笔纹理、马克笔笔尖、荧光笔透色和彩虹效果的完整交换使用原生文件或图像导出。

## 代码图表语法子集

本项目自己解析兼容文本语法、布局和生成 SVG，不加载第三方图表引擎。当前覆盖 **22 类图表、46 个综合示例**，每类至少两个互补场景；工作区可按分类或文字搜索名称、说明和源码。模板选择、注释和修改方法见 [语法和模板导览](DIAGRAM_SYNTAX.md)。支持范围限于下表的语法子集。语法错误保留原始行号，部分错误还包含列号；不支持的语句会报错，不会静默丢弃。源码中的 HTML 不执行，图形标签使用纯文本。

编译器同时生成源码范围到图元 ID 的映射，用于左侧光标或选区与右侧高亮联动。流程图和块图同一行中的节点和连线按独立范围定位；其他类型按声明、字段、关系或数据项定位，一个源码范围可以对应多个原生图元。空白、注释和没有对应图元的语句不高亮；标题、分区或设置有明确图元目标时可以定位。编译错误或新输入尚未得到预览时清除旧高亮。映射和高亮只存在于运行时，不修改源码、场景数据、保存状态或图像导出。

### 流程与结构关系

| 类型 / 开头 | 已实现语法 | 主要边界 |
| --- | --- | --- |
| 流程图 `flowchart` / `graph` | `TD/TB/LR/RL/BT`；连接链、`&` 扇入扇出；嵌套 `subgraph/end`、组内方向和组端点；多种原生形状及 `@{shape,label}`；实线/虚线/粗线、反向/双向/无箭头、圆/叉端标、隐藏布局连接；`classDef/class/style/linkStyle`、`:::类名`、标签、分号及注释 | 样式为安全属性子集；体育场形、子流程形等近似会提示；圆/叉端标为静态装饰；自定义虚线间隔近似为现有线型；不执行点击、脚本或远程资源 |
| 时序图 `sequenceDiagram` | `title`、`participant/actor` 别名、隐式参与者、消息及多方注释；`activate/deactivate`、消息 `+/-` 激活；嵌套 `loop/alt/opt/par/critical/break/rect` 与 `else/and/option/end`；`autonumber` 起值、步长、暂停和恢复；取消叉端与异步开放箭头 | 不支持动态创建/销毁参与者、`box` 分组或脚本；箭头实心/开放差异会统一并提示；片段、激活和分支必须正确闭合匹配；副本不再按时序结构自动重排 |
| 类图 `classDiagram` | 类声明、别名、属性/方法、`<<stereotype>>`、方向和基本关系；`namespace ID["别名"] { ... }`；`note "文字"` 或 `note for ID "文字"` | 类 ID 在全图唯一；命名空间最多 30 个、8 层；不支持源码样式或点击交互；继承/组合/聚合端标在副本中为静态装饰 |
| 状态图 `stateDiagram-v2` / `stateDiagram` | 状态、别名、描述、转移、局部起终点；复合 `state ID { ... }` 和组内方向；`choice`、`fork/join`；单行或多行 `note left/right of ID` | 局部同名状态与局部起终点分别解析；注释自动排在图下方并连到目标，`left/right` 不保证绝对位置；不支持并行区域分隔符 `--` 或历史状态 |
| 实体关系图 `erDiagram` | 实体与别名、类型/字段、`PK/FK/UK`、字段注释、识别/非识别关系、基数和方向 | 基数端标在可编辑副本中为静态元素；不支持自定义样式 |
| 分支历史图 `gitGraph` | `commit` 的 `id/tag/type`、`branch` 的 `order`、`checkout/switch`、双亲 `merge`、`LR/RL/TB/BT`；`cherry-pick id:"已有提交"`，可加 `parent` 和 `tag` | 新建分支后自动切换；只能摘取其他分支的已有提交，摘取合并提交必须指定其真实父节点；产生独立新提交与摘取关联，不执行真实版本操作；不支持初始化配置 |
| 需求图 `requirementDiagram` | `direction`；六种需求节点、`element`；`id/text/risk/verifymethod` 或 `type/docref`；七种关系的双向书写 | 风险仅 `low/medium/high`，验证方式仅 `analysis/inspection/test/demonstration`；不支持额外样式、未知或重复字段 |
| 系统上下文系列 `C4Context` / `C4Container` / `C4Component` | `title`；`Person/System`、`Container/Component` 及数据、队列、外部变体；普通/企业/系统/容器边界嵌套；基本与方向关系 | 容器/组件参数为 ID、名称、技术和可选描述；图形本地简化，方向提示交给统一布局并提示；不支持其他图表头、任意样式配置或远程图标 |
| 架构图 `architecture-beta` / `architecture` | `group/service id(icon)[名称] in group`、嵌套组；`junction ID`；`L/R/T/B` 端口、`service{group}` 边界端口和直接组端口；双向/单向/无箭头及标签 | 连接点为真实圆点，图标为本地基础图形；未知引用和组循环会报错；端口转为自由坐标，在副本中不随节点移动重算；不加载远程图标 |

流程图的 `style`、`classDef` 与 `linkStyle` 接受 `fill`、`stroke`、`color`、`stroke-width`（`0..16`）、`font-size`（`8..72`，子图标题不超过 `32`）、`opacity`（`0..1`）、`stroke-dasharray` 和 `text-align`。`color` 共用轮廓与文字颜色，会提示这一外观边界；自定义虚线间隔映射到当前实线/虚线/点线。`linkStyle` 使用从零开始的连线编号或 `default`，不存在的编号会报错。`~~~` 参与布局但不显示连接，圆/叉端标在画布副本中是静态装饰。

时序图支持正确嵌套的片段和激活栈。消息中的 `+` 激活接收方，`-` 结束发送方的当前激活；`activate/deactivate` 可显式控制，同一参与者最多嵌套 16 层。`else`、`and`、`option` 分别用于相应条件、并行、临界片段；未闭合片段、没有匹配的结束激活或错误分支会按源码行号报错。编号暂停后可 `autonumber resume`，继续使用原有步长。

需求节点包括 `requirement`、`functionalRequirement`、`interfaceRequirement`、`performanceRequirement`、`physicalRequirement` 和 `designConstraint`；关系包括 `contains`、`copies`、`derives`、`satisfies`、`verifies`、`refines` 和 `traces`。系统上下文系列保留 `Person`、`System`，并支持 `Container`、`Component`；系统、容器、组件可使用 `Db` / `Queue` 后缀，节点可使用 `_Ext` 后缀。人物与系统接受可选描述，容器与组件另需技术字段。

甘特图的 `axisFormat` 支持 `%Y-%m-%d`、`%m-%d`、`%d`。`after a b` 取所有依赖任务的最晚结束时间；省略开始时间时沿用上一任务的结束时间，第一项不能省略开始条件。普通时长至少一天，里程碑使用 `0d`。`until ID` 让任务在目标任务开始时结束，目标必须可解析且不能形成循环。

未配置工作日历时按连续日历日计算。`excludes` 接受以逗号分隔的 `weekends`、英文星期名或 `YYYY-MM-DD`；`includes` 只接受日期，并覆盖对应日期的排除设置。启用工作日历后，非里程碑的开始日期顺延到可用日，`Nd/Nw` 只计可用日，**`1w` 表示 7 个可用日**；显式结束日期仍为不包含的边界。没有预置节假日表，需在源码中列出日期。`tickInterval Nd/Nw` 控制连续日期刻度，最多 200 个刻度；总跨度最多 36,525 天。例：

```text
gantt
  title 交付计划
  dateFormat YYYY-MM-DD
  axisFormat %m-%d
  excludes weekends, 2026-10-08
  includes 2026-10-10
  tickInterval 1w
  section 准备
  需求整理 :done, requirements, 2026-10-01, 3d
  section 实施
  开发 :active, build, after requirements, 1w
  验证 :crit, verify, after build, 2d
  完成 :milestone, complete, after verify, 0d
```

### 源码与可编辑副本

文本可保存为 `.owflow` 或导出 `.mmd`；`.mmd`、`.mermaid` 导入保留源码，只有成功编译后才能导出图像或创建可编辑画布副本。副本由形状、文字、连线、笔迹等原生元素组成，不包含图表引擎或嵌入式 SVG 图片，不与源码双向同步。手动修改柱形、扇区或时间条不会重新求值或自动调整其他数据项。

全局风格应用于完整编译场景，预览、图像导出和可编辑副本使用相同的结果；副本保留当时的具体元素样式。风格不会修改图表数据或源码。纯文本导出只保存源码，不携带 `diagramStyle` 或新增初始化指令；需要保留风格时，请保存 `.owflow`。

类图与实体关系图的卡片内容作为组合保留，普通绑定连线可以跟随移动，但继承、聚合、流程图圆/叉端标及 ER 基数端标不会随节点移动重算。架构图为保留精确端口坐标使用自由端点，副本中移动节点后需手动重连。命名空间、复合状态、子图和时序片段转成原生边框与图元，不保留语法的严格层级或自动重排规则。需要重算布局时，应修改源码并重新生成副本。
