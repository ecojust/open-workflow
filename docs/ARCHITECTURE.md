# 架构

Open Workflow 提供画布和代码图表两个入口，共用自己的场景模型。流程图和白板作为可插入的画布模板，已有 `flow`、`board` 文档仍使用原兼容值读取并进入同一画布编辑器。Vue 3 管理工作台和编辑界面，Tauri 2 管理原生窗口与文件访问；SVG 绘制、交互、布局、代码图表解析和格式转换均由仓库内的代码实现。

## 数据流

```text
flowchart LR
  Native[原生 owflow] --> Validate[文档校验]
  External[图形 XML / 白板 JSON] --> Convert[自研格式转换]
  Convert --> Validate
  Validate --> Document[WorkflowDocument]
  Text[代码图表源码] --> Parser[自研子集解析]
  Parser --> Scene[统一 Scene]
  Document --> Editor[SVG 画布交互]
  Editor --> Commit[一次操作提交]
  Commit --> History[文档快照历史]
  Commit --> Document
  Document --> Draft[IndexedDB 草稿]
  Document --> File[owflow 文件]
  Document --> Scene
  Scene --> SVG[SVG 绘制和导出]
  Scene --> Output[格式导出]
```

以上文本描述数据流；应用的代码图表编译器独立解析兼容语法，不依赖第三方图表运行库。

## 场景与交互

文档使用独立于 DOM 的 JSON 数据。形状保存世界坐标和尺寸，连线使用稳定 ID 绑定节点，笔迹保存点列；`stroke.closed` 可将点列绘制成闭合填充区域，供扇区、流带、雷达图和自定义多边形使用。元素数组顺序决定绘制层级，可选的 `groupId` 表达单层组合。视口平移缩放只改变坐标转换，不修改文档中的几何数据。

绑定边的可见端点通过节点边界求交获得。创建连线和拖动端点重新连接时，吸附范围保持为 **14 个屏幕像素**，换算到世界坐标后根据图形轮廓计算距离；椭圆按曲线计算，三角形、六边形、星形等按各自轮廓计算，云形和圆柱的曲线使用采样轮廓。不会把非矩形图形的整个外接矩形当作可吸附内部。内部命中优先最上层图形，外部候选优先距离最近的轮廓。独立文字不是连接目标，锁定节点仍可被连线绑定。

四方向大括弧是原生形状，以开放曲线绘制，不填充封闭区域。几何层按曲线轮廓计算命中、吸附和连线落点，不把括弧内侧留白当作封闭形状内部；文字边界位于括弧内侧。画布与 SVG 导出使用同一套曲线路径和文字布局。

节点移动或调整尺寸后，SVG 使用最新场景重新计算路径；端点拖到吸附范围外可成为自由端点。绑定持久化的是节点 ID，可见落点按路由重新计算，不保存鼠标吸附时的固定端口位置。直线和正交线采用基本几何路由，没有障碍物避让或复杂布线求解器。

点阵对齐世界坐标原点，屏幕间距随缩放维持在 20–40 像素，半径维持 1.25 像素。点色根据实际背景的相对亮度选择，并计算透明度混合后的对比度；百分比 RGB、HSL、命名色及透明色使用相同的判断。文档背景只在画布容器绘制一次，透明部分叠在当前主题底色上。右下角可直接开关点阵，开关状态随文档保存并支持撤销。点阵不进入 SVG/PNG 导出。可选的网格吸附与点阵显示分开，位置吸附使用固定的 20 个世界坐标单位。

工具栏悬浮于画布上方，图形素材库默认收起。工作台、画布、文字绘图、模板面板和右键操作使用共用 `AppIcon` 的 SVG 路径，操作图标不依赖字符字体或远程图标服务。双击图形或连线进入文字编辑；选择工具下双击空白处创建文字。右键菜单调用同一套编辑操作，提供置顶、置底、上移一层、下移一层、文字编辑、复制、锁定/解锁、删除及图像导出。

连续绘制工具锁默认关闭：绘制完图形、笔迹或连线后返回选择；开启后保留当前绘制工具，`Esc` 关闭工具锁并返回选择。工具锁与默认连线设置属于当前编辑器状态，不写入文档或文档历史。新建连线默认使用 `orthogonal` 路径和 `end` 箭头，绘制前可选择直线/直角折线及无/单/双箭头；创建后的具体取值作为连线数据保存。按住 `Shift` 绘制矩形、椭圆、菱形、三角形、六边形或星形时保持等宽高。

画布在手势开始时保存场景起点，移动中维护本地预览，抬起时发出一次 `change(scene, label)`。取消手势恢复起点；选择、平移和缩放不写入文档历史。切换标签、保存、导出或执行历史操作前，外壳调用编辑器 `flush()` 提交进行中的手势、文字和属性编辑。

自动布局从节点的入边关系计算层级，再按方向安排节点。它保留锁定图形位置，对环路采用确定性回退；没有声称全局最优、最少交叉或自动解决全部重叠。复杂图仍可手动调整。

## 画布整理与模板

形状库在基础图形上增加三角形、六边形、星形、平行四边形、圆柱、云形、四方向大括弧与分区框架。橡皮擦按绘制顺序命中元素并整件删除，遵守锁定状态；一次擦除手势可一次撤销，不进行像素擦除或笔迹切段。

笔迹可选 `brush` 保存圆头笔、铅笔、马克笔、毛笔、荧光笔或彩虹笔类型，`pressures` 与点列逐点对应。缺少两者的旧笔迹继续使用原绘制路径，不在读取时改成新笔触。各笔触共用结构化点列：圆头笔使用圆形笔端，铅笔增加稳定纹理，马克笔采用固定倾斜的扁笔尖，毛笔随压力与笔端位置改变宽度，荧光笔保持透色，彩虹笔按行程分配颜色。画布与 SVG/PNG 导出共用笔触渲染，笔迹仍可选中、移动、复制、擦除和切换类型。

触笔事件采样归一化压力，六种笔触均据此改变可见粗细；鼠标或关闭压感时使用稳定压力。彩虹笔在色段边界插值压力，面板禁用不参与其绘制的单色设置。荧光笔在用户不透明度之上使用 `0.32` 透色系数。平滑在录入点列时执行，文件保存最终采样坐标，不额外保存平滑开关。笔触面板的设置用于后续绘制，各类型在当前编辑器中分别记住设置，不写入偏好存储；选中笔迹的属性面板只修改当前笔迹并遵守锁定状态。一次绘制仍只提交一次历史。激光指示使用短暂的覆盖层轨迹，松开后约 900 毫秒内淡出；它不添加场景元素，也不触发历史、草稿或文件修改。

组合使用平面 `groupId`，普通选择扩展到整组，`Alt` 点击可选择成员；再次组合会合并所选未锁定成员，不建立嵌套树。六种对齐将组合当作整体，锁定单位保持位置并可作为对齐参照。水平/垂直分布均衡元素边缘之间的间距，保留两端位置，锁定单位成为额外锚点。已有节点绑定的连线继续随节点计算。

框架以边框和标题区域接受选择，内部空白不遮挡其他元素。拖动框架时，根据手势开始时的几何范围收集完整包围的内容，并移动其中未锁定的元素；调整框架尺寸不缩放内容。框架不维护父子引用，也不裁剪内容。

统一模板面板提供流程图、白板，以及头脑风暴、四象限分析、任务看板和会议复盘，均由本地原生图元组成。插入时重新生成元素与组合 ID、重映射绑定、应用当前全局线条风格并定位到视口附近，保留原有内容，一次提交历史。模板不创建另一种编辑模式，也不改变已有文档的兼容类型。看板模板是可编辑图形与便签，没有任务服务或自动流转状态。

## 外观与选区导出

每个元素保存自己的 `style`，画布通过 `scene.defaultStyle` 保存后续图形和连线的默认样式。新笔迹的颜色、粗细和不透明度由笔触面板独立管理，不随全局设置覆盖各笔触的预设或临时偏好。整洁/手绘风格使用 `roughness`，实线/虚线/点线使用 `strokePattern`；旧的 `dashed` 字段继续参与兼容读取。缺失的新字段按整洁外观、原有线型和默认样式补全，原生文档版本仍为 `1`。

全局操作只更新用户明确调整的线条外观、线型、线宽或颜色，同时写入现有元素与 `defaultStyle`，**包括锁定元素**。这是显式的画布整体外观操作；普通单元素样式、位置、文字、图层及删除仍遵守锁定保护。元素独立样式不会影响其他元素，下次全局调整同一属性时会统一覆盖。全局修改也进入文档历史，可以整体撤销。

专用笔触由 `brush` 决定外观，不叠加 `roughness` 或 `strokePattern`；选中这类笔迹时不显示无效的整洁/手绘与虚点线控件。全局粗细与颜色仍可调整其样式，但彩虹笔的可见颜色由行程决定。没有笔触和压力元数据的旧笔迹继续使用原来的线条风格规则。

手绘路径由本项目生成，SVG 屏幕绘制和图像导出共用渲染代码。该外观与线条的实际绑定几何分离，图形与连线仍保留结构化可编辑数据。手绘是视觉近似，不是对其他渲染器笔迹效果的复刻。

代码图表在编译后的完整场景上应用独立的全局风格：经典、极简、蓝图、水墨、手绘、森林、海洋、落日、紫雾和夜色。`applyDiagramStyle()` 每次从未应用风格的编译结果复制场景，再统一调整背景、形状、笔迹、连线、数据系列及图例的颜色和线条外观；文字按其背景校正对比度。它不改变源码、数据值、几何布局或绑定关系，避免反复切换造成颜色累积变化。经典风格保留编译器原始样式。

文档可选字段 `diagramStyle` 保存风格 ID，缺失或未知值归一为 `classic`。预览、图像导出与可编辑副本都使用相同的风格转换；字段纳入内容比较、历史和草稿，因此更换风格属于可撤销的文档修改。导出纯源码保留原文，不插入风格指令；风格需要随 `.owflow` 一同保存。可编辑副本直接保留生成后的具体样式，不与原代码图表后续的风格切换联动。

整图和选区 SVG/PNG 导出共用外壳的文件出口。选区导出先复制所选元素，保留它们之间的节点绑定；边连接到选区外节点时，按完整场景计算当前端点后改为自由端点，因此无需把未选择的图形带入导出。选择状态和这种导出转换不修改原文档。

## 文档历史与保存状态

每个标签维护自己的 `DocumentHistory`。相同内容不会重复入栈；正常编辑清除后续重做，撤销和重做恢复完整快照。历史限制为最多 60 份快照，按估算字符串大小执行约 24 MiB 预算；至少保留当前和前一快照，因此两个大文档快照可以超过该预算。历史不持久化到文件或草稿。

`contentKey()` 比较实际可编辑内容，时间戳和磁盘路径不参与比较。文件保存捕获调用时的文档快照；异步写入期间发生的新修改不会被标记为已保存。文档的 `savedKey` 与草稿写入状态分别记录，避免把“草稿已保存”误当成文件已更新。

## 本地存储与文件访问

草稿按文档 ID 存入 IndexedDB。顶部自动保存开关默认开启，设备偏好存于 `localStorage`；开关只控制本地草稿，从不自动写原文件。开启时，修改经过短暂延迟触发草稿写入，同一文档的任务串行执行，避免旧快照覆盖较新的快照；每次写入以事务完成事件判断成功。

关闭开关清除尚未执行的定时任务，并使队列中尚未开始的自动写入失效；已开始的写入可以完成，已有草稿保留。编辑仍参与未保存状态判断及关闭/离开保护。重新开启会先 `flush()` 当前未提交编辑，再为所有打开标签补存最新草稿。手动保存不受开关限制，写入文件后同步本地草稿。

读取时重新校验数据，损坏草稿跳过并提示，原记录不自动删除。主题、侧栏偏好和会话标签 ID 同样使用少量 `localStorage`。自动保存偏好不写入 `.owflow`，也不代表文件保存授权。

草稿仅存在当前设备的当前工作区，浏览器卸载前的异步操作也不能保证在进程被强制终止时完成。需要长期保存或迁移的内容应写入 `.owflow`。同一草稿的多窗口并发编辑没有合并协议，最后完成的写入可能覆盖其他窗口的草稿。

浏览器通过文件选择器读取、通过下载保存。桌面版通过 Rust 系统文件选择器授予本次会话的路径权限；覆盖原文件时校验 SHA-256 版本，再写入同目录临时文件并替换。重启后从草稿恢复不会复用磁盘路径授权。具体平台限制及剩余的文件并发竞争边界见 [DESKTOP.md](DESKTOP.md)。

## 文本和格式边界

代码图表源码是该文档的事实来源，编译结果只用于预览、导出和创建独立画布副本；没有从任意画布反推源码的双向同步。延迟输入合并一次文本提交，无法识别的语法保留原文并按原始行号报错。模板目录按类型与分类提供搜索，每类包含可编译示例；用模板替换已有源码需要确认，并作为一次历史操作。

编译入口覆盖 22 类明确的语法子集：流程图、时序图、类图、状态图、实体关系图、分支历史图、需求图、系统上下文图、架构图、饼图、甘特图、柱线图、象限图、桑基图、雷达图、矩形树图、思维导图、时间线、用户旅程、看板、块图和数据包图。编译器输出统一的 `{ kind, scene, warnings, sourceMap }`，不调用第三方绘图引擎。逐类语法与不支持项见 [FORMATS.md](FORMATS.md#代码图表语法子集)。

`sourceMap` 保存原始源码的半开 UTF-16 字符范围与图元 ID，保留原始换行和字节序标记对应的位置。文本框会把换行归一化为 LF，编辑器先将光标和选区偏移转换回原始源码位置，再查询映射。映射由解析与生成图元时建立，按 ID 查找，避免同名标签串位；流程图和块图保留同一行中的独立节点与连线范围。光标或选区变化只查询现有映射，不重新编译，也不改变场景样式。高亮通过独立 SVG 覆盖层显示，边与笔迹沿真实路径描边，节点显示边框；“定位图形”显式将目标滚到预览中央，普通光标移动不自动滚屏。

输入后、尚未完成新编译时暂停高亮，编译错误时也清除高亮，防止旧图与新源码错位。空白行、注释及没有对应图元的语句不产生高亮。映射与当前光标都是临时编译和界面数据，不进入 `.owflow`、草稿内容、文档历史或导出；失焦可以保留当前定位供对照查看。

每类按其含义生成几何数据：饼图用闭合扇区，甘特图按 UTC 连续日历日绘制任务与依赖，柱线图使用数值坐标轴，桑基图用与数值成比例的闭合流带，雷达图沿各维度投影，矩形树图按权重划分面积。数据包图按固定 32 位行宽切分字段。无效日期、依赖环、越界数据和未实现的指令明确报错；图表模块在生成后校验场景并限制复杂度。

可编辑副本中的图表是普通图元，不再是持续求解的语义图表。类图和实体关系图的卡片组件使用组合，普通绑定连线可跟随卡片；继承/聚合等装饰端标及 ER 基数端标是静态元素，移动卡片后不自动重算。架构图为保留 `L/R/T/B` 端口位置使用自由端点，副本中不会自动跟随节点。系统上下文图使用本地图形，方向提示统一交给自动布局；架构图标也使用本地基础形状与原图标名称。这些限制随对应编译结果显示提示。

外部格式转换后保留 `importSource`，使用户可以取回导入时的完整文本。它不是对未知高级属性的可编辑支持，也不会把后续画布修改合并回原文。转换详情见 [FORMATS.md](FORMATS.md)。

图形 XML 与白板 JSON 的线型和手绘标记映射到同一套元素样式，并携带默认样式、扩展形状、组合或闭合图形所需的元数据，供重新导入时恢复。外部嵌套分组会展开或合并，框架裁剪关系不保留。不同软件可能忽略元数据，手绘路径、抖动强度和自定义线段间隔也可能不同；不能把标记往返当成外观完全一致。

大括弧导出到上述格式时使用开放线条或笔迹，并附带原生形状、尺寸和文字元数据；重新导入可恢复为原生括弧并显示兼容提示。外部编辑器可能只保留普通线条与文字，不保留括弧编辑和节点绑定语义。

SVG 输出对文字和属性做转义，图片只接受受限的内嵌 PNG/JPEG/WebP；不执行导入文档的 HTML、脚本或远程资源。图形 XML 的压缩页面用通用压缩库 `fflate` 解压，解析后映射到自己的数据结构。

## 检查与扩展

`npm test` 覆盖文档校验、保存往返、历史、几何、绑定、布局、画布组合与整理、笔触与压力、各类图表的有效和无效输入、源码映射、SVG 转义及外部格式转换。`npm run test:browser` 检查真实 Chromium 中的绘制、拖动、撤销、模板、图表预览、导入导出、草稿、关闭保护和窄屏界面；画布套件检查自动保存开关、大括弧、连续绘制及新建连线设置，笔触与光标套件检查六种笔触、临时激光轨迹和 22 类代码图表的光标联动。浏览器套件可按需启动开发服务，也可通过 `BASE_URL` 连接已启动的预览，运行方法见 [README](../README.md#运行)。桌面 Rust 测试检查文件授权、外部修改冲突和写入行为。CI 的平台构建成功不能代替对应系统的实机交互验收。

新增可编辑图元时，应同时更新类型、校验、几何、SVG、编辑交互和相关导出；外部格式不支持的部分需要明确提示。若改变原生文档语义，应增加格式版本和迁移逻辑。新图表类型需要加入编译入口、目录和有效模板，并验证错误行号、几何含义、保存回读与 SVG 输出。当前没有协作或云同步服务；正式安装包及对应源码归档通过版本发布页分发。
